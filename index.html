Three-tower homelab

NixOS · Nix flakes · Tailscale · sops-nix · restic · Ollama

A small lab of two desktops, a Proxmox host, a backup box and an always-on VM, all described in one Nix flake. Every machine can be rebuilt from git, and every change is built and checked before I switch to it.

  • Safe deploys: deploy-rs with magic rollback. I tested it by deliberately breaking SSH and watching it undo the change.
  • One list of ports: a registry that opens firewall ports only on the private network, and fails the build if two services claim the same port.
  • Backups that can't be erased: nightly restic to an append-only server, with heartbeats that alert my phone when a backup goes missing.
  • Files that clean themselves: a sorter with a 30-day quarantine instead of deletion, and one command to undo a day.
  • Local AI on a budget: a 20B model on a 16 GB GPU that steps aside when I game, plus private search and a research tool that stays on the private network.
  • Agents with guardrails: coding agents run under enforced deny lists (no pushes, no deploys, no secrets), because instructions alone were not enough.

The repository is private because it holds infrastructure details. I'm happy to walk through it on a call.

My Three Body CV

Next.js · React 19 · TypeScript · Tailwind · XState · Playwright

My CV as a 16-bit space site. The CV itself is plain, recruiter-friendly HTML. Behind it sits a live three-body physics simulation running in a Web Worker, and a few hidden extras for people who look around.

  • One source of truth: the CV lives in a validated JSON file, and the page, the PDF and the site's built-in assistant are all generated from it.
  • Accessible and fast: automated accessibility and end-to-end tests run in CI. Lighthouse performance was 98 on mobile and 100 on desktop (measured 27 October 2026).
  • Static and cheap: a static export deployed to GitHub Pages by CI on every merge.
