# Portfolio

A one-page static portfolio (plain HTML and CSS, no build step), deployed to GitHub Pages by
`.github/workflows/pages.yml` on every push to `main`.

Preview locally: `python3 -m http.server -d . 8000`, then open http://localhost:8000.
Edit `index.html` and `style.css`. Keep infrastructure details (IPs, hostnames, keys) out of it.
